# My Personal Portfolio

My personal portfolio website for my web development project.

## About This Project

This website introduces me, showcases my work and projects, and shares my personal goals and interests.

## Website Pages

- **Home:** Introduction and overview.
- **Projects/Work:** My experience, creative projects, and future goals.
- **About/Contact:** My story, dreams, and contact form.

## Accessibility Improvements

- Used WAVE to evaluate all three website pages for accessibility issues.
- Added alternative text to images that needed descriptions.
- Corrected page language declarations.
- Reviewed page structure and navigation to improve accessibility.
- Added accessible labels to contact form fields.
- Used a fieldset and legend to group related form controls.

## Visual Design

- Used a consistent red, black, white, and gray color palette.
- Used proximity to group related information into sections.
- Used consistency to maintain the same navigation and overall design across pages.

## Technologies Used

- HTML
- CSS
- WAVE Web Accessibility Evaluation Tool
